# POS System (Point of Sale)

 Overview
This project is a Point of Sale (POS) system developed to manage inventory, sales, and daily operations in a real-world environment.

It was designed to support operational workflows in a camp/store setting, replacing manual processes with an integrated digital solution.

---

Problem Solved
Many small organizations rely on manual tracking for inventory and sales, which leads to:
- Errors in stock control
- Inefficient sales processes
- Lack of reporting visibility

This system solves these problems by:
- Automating inventory tracking
- Managing multiple payment methods
- Providing real-time sales data

---

 Features
- Product and inventory management
- Sales processing with multiple payment methods (cash, card, digital)
- Automatic calculation of totals and change
- Sales reporting and tracking
- Customer management (optional)
- Integration-ready for barcode scanning

---

Technologies Used
- C#
- .NET / WPF
- SQLite / SQL Server
- MVVM architecture
